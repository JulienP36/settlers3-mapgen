# Settlers III MapGen v1.7 STABLE

Date: 2026-08-21

## Scope

v1.7 establishes the first complete Statistics / Graphs analysis foundation around the validated v1.5 generation engine.

## Highlights

- Structured Statistics/debug report with exhaustive terrain/object inventories and normalized densities.
- Interactive Graphs with semantic colors, A/B comparison, contextual tooltips and ID information.
- Player-local resource analysis, hydrology/component analysis, height distribution and start-distance analysis.
- JSON/CSV/PNG export support for analysis workflows.
- Session caches and A/B workflow improvements.
- FR/EN support for the Statistics/Graphs surfaces.
